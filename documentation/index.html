    Overview

    A complete learning platform in two applications: a Laravel API with a Filament admin panel, and a Next.js storefront. This manual covers what it does, how to install it, and how every screen fits together.

    Seven chapters. About 40 minutes to read end to end. If you only want the site running, jump to Installation.

    What this product is

    A self-hosted marketplace for online courses. Instructors publish lessons, students buy and watch them, and administrators review everything from a control panel — with no code editing required to run the site day to day.

    The download contains two applications that share one database:

    • Backend — a Laravel 12 application that serves the REST API under /api/v1, owns the admin panel at /admin, stores and streams lesson media, talks to payment gateways, and issues certificates.
    • Storefront — a Next.js 15 front end that renders the public site (catalog, course pages, checkout) and the logged-in dashboards for students and instructors.

    Everything a site owner normally wants to change at launch — site name, logo, favicon, homepage sections, footer, terms and privacy text, cookie banner, payment gateways, instructor commission, payout methods, and where lesson videos are stored — is edited in the admin panel and picked up by the storefront immediately.

    How the two applications fit together

    The storefront never talks to the database. It calls the API as the logged-in user, using Sanctum session cookies that the backend issues; the API enforces every permission, price, and access rule.

    Browser

    localhost:3000 — public pages, student dashboard, instructor workspace. Server-rendered by Next.js, then hydrated.

    Laravel API

    localhost:8000/api/v1 — authentication, catalog, cart, checkout, enrollments, progress, quizzes, certificates, instructor authoring, payouts. Session cookie + CSRF for browser requests.

    Database

    MySQL 8 or MariaDB 10.4+. Queue jobs, cache, and sessions use the same connection.

    Private media

    Local private disk while developing, any S3-compatible bucket in production. Never public.

    Payment gateways

    Stripe, PayPal, Mollie, Razorpay. Gateways call back to the webhook endpoints after payment.

    Mail

    Verification links, password resets, instructor and payout notifications.

    The admin panel lives on the backend

    Filament renders at http://localhost:8000/admin. Students and instructors never see it; they use the Next.js storefront only. Reach for the panel when you need to approve a course, issue a refund, edit legal text, or change a gateway key.

    Three roles, one platform

    Every account has one role, and each role sees a different surface.

    How each role is created and what it can reach
    Role How an account gets it What it can do
    Student Default for every new registration Browse and buy courses, watch lessons, track progress, take quizzes, earn and download certificates, review courses, keep a wishlist, open support tickets, export or delete their own data.
    Instructor Applied for from the storefront, approved by an administrator Everything a student can do, plus: build courses with a step-by-step authoring flow, manage curriculum and attachments, write the course quiz, see sales and earnings, and request payouts.
    Admin Created by the database seeder, or promoted in the panel Full control: users, instructors, courses and approvals, categories, coupons, orders, payments, enrollments, certificates, quizzes, content, legal text, support tickets, notifications, and every setting.

    Technology and versions

    The stack is deliberately mainstream: Laravel and Next.js, no proprietary runtime, nothing that needs a special host.

    Layer What runs there
    Front end Next.js 15.3 (App Router, React 19), Tailwind CSS 4, Radix UI primitives, TanStack Query 5 for data fetching, axios for API calls, TipTap and BlockNote for rich text.
    Backend Laravel 12 on PHP 8.2+ (developed on 8.4), Filament 4 admin panel on Livewire 3, Sanctum 4 for cookie-based single-page-app sessions, Socialite for Google sign-in.
    Database MySQL 8 or MariaDB 10.4+. Queue, cache, and session drivers all use the database by default, so there is no Redis requirement.
    Payments Stripe, PayPal, Mollie, and Razorpay, each switchable in the admin panel; cash-free checkout is also supported for free or fully discounted carts. Stripe and Mollie use signed webhooks; PayPal and Razorpay verify on return.
    Media Lesson videos live on a private disk: local by default, or any S3-compatible bucket (AWS S3, Cloudflare R2, MinIO, DigitalOcean Spaces, Wasabi). Two delivery modes: stream through the app, or redirect to time-limited signed URLs.
    Certificates Rendered as PDFs with dompdf, stored with a public verification code so anyone can check a certificate at /certificates/{code}.
    Testing Pest 3 on PHPUnit 11, with feature tests covering checkout, approvals, payouts, media access, certificates, and authentication.

    What ships in the box

    Two independent applications, plus this manual. You can rename or move the folders; each one is deployed separately.

    lms/
├─ localhost/                     Laravel 12 application — API, admin panel, jobs, tests
│  ├─ app/Filament/                 admin panel: resources, pages, widgets
│  ├─ app/Http/Controllers/         public, auth, instructor, and webhook controllers
│  ├─ app/Services/                 payments, payouts, approvals, certificates, storage
│  ├─ app/Console/Commands/         media:migrate-to-cloud — move media to a bucket
│  ├─ database/migrations/          35 migrations, run with migrate --seed
│  ├─ database/seeders/             homepage content, features, default administrator
│  ├─ routes/api.php                every API route, all under /api/v1
│  └─ tests/Feature/                Pest feature tests
├─ frontend/                      Next.js 15 storefront and dashboards
│  ├─ src/app/(main)/               public site: catalog, course, cart, checkout, legal pages
│  ├─ src/app/(dashboard)/          student and instructor areas behind the login
│  ├─ src/lib/api/                  one module per API area
│  └─ src/components/               UI: course detail, teaching tools, quiz, payments
└─ documentation/                 this manual — open index.html in a browser

    The documentation is static HTML, CSS, and JavaScript with no build step. Open documentation/index.html directly, or serve the folder from any web server.
